================================================================================
  MMEAN / scripts — 실행 스크립트
================================================================================

역할
----
장 자동화, 야간 최적화, 유틸리티 등 직접 실행하는 스크립트 모음.
라이브러리로 import되지 않고 단독으로 실행된다.

파일 목록
---------
day_auto_run.py
  - 주간장 자동 최적화 실행기
  - DaySimRunner를 스케줄에 따라 자동 실행
  - 랜덤탐색 → 베이지안 최적화 → 검증 순서

night_auto_run.py
  - 야간장 자동 최적화 실행기
  - day_auto_run.py에서 야간 전환 시 호출

night.py
  - 야간장 최적화 진입점
  - 직접 실행: python scripts/night.py

git_push.py
  - 코드 변경사항 자동 git 커밋 + push
  - gitput.bat에서 호출

자동화 스케줄 (Windows 작업 스케줄러)
--------------------------------------
  08:44  → analyzer_app.py 시작 (주간장 시작)
  15:45  → 자동 종료 (engine_runtime 내장 watchdog)
  18:00  → analyzer_app.py 시작 (야간장 시작)
  06:00  → 자동 종료 (engine_runtime 내장 watchdog)

build_entry_snapshots.py
  - Entry RAG Phase 0 — 진입 직전 스냅샷 추출 파이프라인
  - 소스: sim(sim.db 배치 수만건, 기본) / trades(mmean.db 실거래)
  - sim_trades(sim.db) × regime_ticks(mmean.db) 조인
  - 진입 open_ts 직전 45초 틱을 집계 → entry_snapshots 테이블(mmean.db) 저장
  - 피처: volume_burst / basis_ema_delta / price_vs_vwap / flow_score /
          fut_fgn_delta / ema_fast_slope / oi_delta (각각 last/mean/slope)
  - 레이블: outcome_class (1=SUCCESS/0=NEUTRAL/-1=FAILURE, session_phase별 임계값)
  - CLI 옵션: --source sim|trades / --since/--until/--window/--dry-run/--reset/--summary
  - 실행 예: python scripts/build_entry_snapshots.py --since 2026-03-01

의존 관계
---------
  scripts → sim_opt(day_sim, night_sim), core
