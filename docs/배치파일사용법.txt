================================================================================
MMEAN 배치파일 사용법
최종 수정: 2026-03-21  (day_pattern.bat 추가)
================================================================================

모든 배치파일은 C:\mme\mmean\ (프로젝트 루트)에서 더블클릭 또는 CMD에서 실행.
conda 환경(mmean)이 활성화된 상태가 아니어도 대부분 내부에서 자동 처리.

────────────────────────────────────────────────────────────────────────────────
1. mmean.bat  ★ 메인 실행파일 ★
────────────────────────────────────────────────────────────────────────────────
목적  : MMEAN 자동매매 엔진 + Flask 대시보드 서버 시작
동작  : conda 환경(mmean) 활성화 → analyzer_app.py 실행
실행  : mmean.bat  (더블클릭)
접속  : http://localhost:5001
참고  : EXECUTION_ENABLED=true 일 때 시작하면 비밀번호 입력 프롬프트 표시 (30초)
        비밀번호 미입력/불일치 시 자동으로 OFF 모드로 다운그레이드

────────────────────────────────────────────────────────────────────────────────
2. sim.bat  — 시뮬레이션 실행
────────────────────────────────────────────────────────────────────────────────
목적  : 파라미터 최적화용 가상매매 시뮬레이션 실행
동작  : sim.py 를 실행 (인자 그대로 전달)
실행  :
  sim.bat                         기본 실행 (대화형 메뉴)
  sim.bat --help                  전체 옵션 확인
  sim.bat --mode day              당일 장중 시뮬레이션
  sim.bat --mode night            야간 시뮬레이션
  sim.bat --mode auto             자동 배치 (day + night 순차)
  sim.bat --date 2026-03-17       특정 날짜 지정
참고  : 결과는 storage/sim.db의 sim_runs / sim_trades / sim_run_summary에 저장

────────────────────────────────────────────────────────────────────────────────
3. rag_build.bat  — RAG 문서 빌드
────────────────────────────────────────────────────────────────────────────────
목적  : LLM이 장중에 참조할 RAG 패턴 문서 생성/갱신
동작  : 메뉴 방식으로 rag/sim_rag_builder.py 실행
메뉴  :
  [1] Phase 1       sim.db → rag_documents 생성 (레짐 태그 포함)
  [2] Phase 2A      rag_documents → pattern_docs 생성 (VS/PC/FC)
  [3] Phase 1+2A    전체 생성 (1→2 순서 자동 실행)
  [4] 재생성        pattern_docs 전체 삭제 후 처음부터 재빌드
  [5] 검증          현재 pattern_docs 상태 점검표 출력
  [6] 종료
실행  : rag_build.bat  (더블클릭)
참고  : sim.bat 시뮬레이션 → 검증 → rag_build.bat 순서로 사용
        장중 실행 중에도 갱신 가능 (WAL 모드 지원)

────────────────────────────────────────────────────────────────────────────────
4. rag_menu.bat  — RAG 빌드 (구버전 메뉴)
────────────────────────────────────────────────────────────────────────────────
목적  : rag_build.bat 의 구버전 (동일 기능, 메뉴 구성 상이)
동작  : rag/ 서브디렉토리 기준으로 sim_rag_builder.py 직접 호출
메뉴  :
  1. pattern_docs 생성 (신규/갱신)
  2. pattern_docs 재생성 (전체 삭제 후 재빌드)
  3. 전체 빌드 (rag_documents + pattern_docs)
  4. 검증 (현재 상태 점검표 출력)
  5. Phase 1 only (rag_documents만)
  0. 종료
참고  : rag_build.bat 과 기능 동일 — 둘 중 하나만 사용

────────────────────────────────────────────────────────────────────────────────
5. db_archive.bat  — DB 아카이브 (C드라이브 → F드라이브)
────────────────────────────────────────────────────────────────────────────────
목적  : 운영 DB(C드라이브)의 오래된 데이터를 F드라이브 누적 아카이브로 이전
        C드라이브 용량 확보 + F드라이브에 전체 이력 보존
동작  : 유지 일수(기본 7일) 기준으로 오래된 데이터를 F:\db 로 복사 후 C드라이브 삭제
메뉴  :
  [1] 용량 현황 확인
  [2] DRY-RUN        이전 대상 건수만 확인 (실제 이동 없음)
  [3] 전체 실행      sim.db + mmean.db 함께 이전
  [4] sim.db만 실행
  [5] mmean.db만 실행
  [6] 유지 일수 변경 (기본 7일)
  [7] F드라이브 중복 데이터 정리 (dedup)
  [8] F드라이브 중복 확인만 (dedup dry-run)
  [0] 종료
실행  : db_archive.bat  (더블클릭)
참고  : F드라이브 없으면 이전 불가 — 외장드라이브 연결 후 실행
        sim.db 3.7GB / mmean.db 384MB 규모

────────────────────────────────────────────────────────────────────────────────
6. purge_sim_trades.bat  — sim_trades 정리 (용량 회수)
────────────────────────────────────────────────────────────────────────────────
목적  : 검증 완료 후 불필요해진 sim_trades 원시 데이터 삭제
        sim.db 용량의 대부분을 차지하는 틱 기록을 정리해 공간 회수
삭제  : status=done AND sim_run_summary 존재 AND 지정 일수 이전 완료 run
보존  : sim_runs / sim_run_summary / sim_adoptions / sim_observations
        (RAG·승격·파라미터 이력에 필요한 테이블은 절대 삭제하지 않음)
메뉴  :
  [1] 현황 확인       sim.db 크기 + 행 수 출력
  [2] 삭제 예정 건수 확인 (dry-run)
  [3] 전체 정리       완료된 run 전부 삭제
  [4] 최근 3일 제외하고 정리
  [5] validation run만 정리
  [6] 직접 입력       --keep-days / --run-type / --run-ids 등 고급 옵션
  [0] 취소
실행  : purge_sim_trades.bat  (더블클릭)
권장  : [2] dry-run으로 건수 확인 후 → [3] 전체 정리 실행

────────────────────────────────────────────────────────────────────────────────
7. day_pattern.bat  — 일별 장세 패턴 분류
────────────────────────────────────────────────────────────────────────────────
목적  : regime_ticks 데이터를 분석해 각 날짜의 장세 패턴을 자동 분류
        → mmean.db의 session_patterns 테이블에 저장
        → 시뮬레이션/RAG에서 장세 유형별 파라미터 선택에 활용
패턴  :
  TREND_UP / TREND_DOWN   추세장 (우상향 / 우하향)
  REVERSAL_UP / DOWN      반전장 (하락→상승 / 상승→하락)
  V_SHAPE                 급락 후 급반등
  MORNING_SPIKE           장초 급변 후 횡보
  CLOSE_RUSH              장후반 방향성 급변
  RANGE_TIGHT / WIDE      박스권 (좁음 <8틱 / 넓음 ≥15틱)
  CHOPPY                  방향 없는 혼조
메뉴  :
  [1] 누락 날짜만 자동 분류    이미 분류된 날은 건너뜀 (일상 실행용)
  [2] 전체 재생성              모든 날짜 처음부터 재분류
  [3] 특정 날짜 분류           날짜 직접 입력
  [4] 저장된 패턴 전체 출력    누적 분류 현황 확인
  [5] 특정 날짜 패턴 확인      날짜 직접 입력
  [0] 종료
실행  : day_pattern.bat  (더블클릭)
참고  : mmean.bat 실행 전 또는 시뮬레이션 전에 실행해두면 RAG 품질 향상

────────────────────────────────────────────────────────────────────────────────
9. install.bat  — 초기 환경 설치
────────────────────────────────────────────────────────────────────────────────
목적  : 최초 1회 또는 새 PC 세팅 시 Python 환경 구성
동작  :
  1. conda 환경(mmean / Python 3.11) 생성
  2. pip / setuptools / wheel 업그레이드
  3. requirements.txt 패키지 설치
  4. environment.yml 내보내기
  5. requirements.lock.txt (pip freeze) 저장
실행  : install.bat  (Miniconda Prompt에서 실행 권장)
참고  : 일반 CMD에서 실행 시 conda PATH 확인 필요
        최초 설치 후에는 사용할 일 없음

────────────────────────────────────────────────────────────────────────────────
10. gitput.bat  — git 푸시
────────────────────────────────────────────────────────────────────────────────
목적  : 변경사항을 git remote(origin)에 푸시
동작  : git_push.py 실행 (커밋 메시지 자동 생성 + push)
실행  : gitput.bat  (더블클릭) 또는 CMD에서 gitput

────────────────────────────────────────────────────────────────────────────────
11. rep.bat  — 시뮬레이션 결과 리포트 (실시간 감시)
────────────────────────────────────────────────────────────────────────────────
목적  : sim.db의 시뮬레이션 결과를 터미널에서 실시간 확인
동작  : sim_opt/sim_report.py --watch 실행
출력  : 전체/일별/월별 손익 요약, 최대 낙폭(MDD), 승률, 손익곡선(ASCII)
실행  : rep.bat  (더블클릭) — 시뮬레이션 실행 중 별도 창에서 띄워두면 편리
참고  : --watch 모드로 실행되므로 결과가 자동 갱신됨

================================================================================
권장 워크플로우
================================================================================

[ 최초 설치 ]
  install.bat → 환경 구성

[ 일상 운영 ]
  mmean.bat → 엔진 시작 → 대시보드(http://localhost:5001) 접속

[ 파라미터 최적화 사이클 ]
  1. day_pattern.bat   장세 패턴 분류 (누락 날짜 보완)
  2. sim.bat           시뮬레이션 실행 (day/night)
  3. rep.bat           결과 실시간 확인
  4. (검증 완료 후)
  5. rag_build.bat     RAG 문서 갱신
  6. purge_sim_trades.bat  sim_trades 정리 (용량 회수)

[ 정기 DB 관리 (주 1회 권장) ]
  db_archive.bat       오래된 데이터 F드라이브로 이전
