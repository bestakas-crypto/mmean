PulseEngine 내부 파라미터 Monte Carlo + Bayesian 최적화 옵션 정의
파일: sim_opt/pulse_sim.py
최적화 결과 DB: storage/pulse_sim.db
실행: pulse_sim.bat (자동 루프) 또는 python sim_opt/pulse_sim.py --dates YYYY-MM-DD

[A-group — 방향 판정 임계값]
────────────────────────────────────────────────────────────────────────────────
옵션명                   변수명                  기본값   탐색범위      타입
────────────────────────────────────────────────────────────────────────────────
BULLISH 판정 임계값      a_bullish_thresh        +4.0    2.0 ~ 8.0    float
  A-group 합계 ≥ 이 값 → BULLISH 후보 판정
  반대(BEARISH) 임계값은 -a_bullish_thresh 로 자동 대칭 적용

외국인 delta 강도 기준   fgn_delta_strong        1000    200 ~ 3000   float
  외국인 선물 순매수 delta > 이 값 → A1 최대 +4점
  외국인 선물 순매도 delta < -이 값 → A1 최대 -4점
  0 < delta ≤ 기준 → +2점 / 0 > delta ≥ -기준 → -2점

flow_score 상단 기준     flow_upper              0.5     0.15 ~ 0.8   float
  flow_score > flow_upper → A3 +2점 (강한 상승 흐름)
  flow_score < -flow_upper → A3 -2점 (강한 하락 흐름)

flow_score 하단 기준     flow_lower              0.1     0.02 ~ 0.3   float
  flow_lower < flow_score ≤ flow_upper → A3 +1점 (약한 상승 흐름)
  -flow_upper ≤ flow_score < -flow_lower → A3 -1점
  -flow_lower ≤ flow_score ≤ flow_lower → A3 0점 (중립)
  ※ 제약: flow_upper > flow_lower

long-short 차이 기준     ls_diff_thresh          0.2     0.05 ~ 0.5   float
  long_score - short_score ≥ 이 값 → A4 +1점
  long_score - short_score ≤ -이 값 → A4 -1점

[B-group — 신뢰 보정 임계값]
────────────────────────────────────────────────────────────────────────────────
옵션명                   변수명                  기본값   탐색범위      타입
────────────────────────────────────────────────────────────────────────────────
EMA 기울기 기준          ema_slope_thresh        0.05    0.01 ~ 0.2   float
  ema_fast_slope ≥ 이 값 → B2 +1점
  ema_fast_slope ≥ 이 값 × 0.5 → B2 +0.5점
  ema_fast_slope ≤ -이 값 → B2 -1점
  ema_fast_slope ≤ -이 값 × 0.5 → B2 -0.5점

베이시스 고/저 기준      basis_high              0.3     0.05 ~ 1.0   float
  basis > 이 값 → B3 -1점 (고평가, 매도 압력)
  basis < -이 값 → B3 +1점 (저평가, 매수 압력)
  ※ basis_low = -basis_high 자동 대칭 적용

B-group confirmed 기준   b_confirm_min           1       0 ~ 3        int
  aligned_B ≥ 이 값 → confirmed 상태 판정
  aligned_B = 0 → weak
  aligned_B < 0 → NEUTRAL 격하 (transition)

[추세 확정]
────────────────────────────────────────────────────────────────────────────────
옵션명                   변수명                  기본값   탐색범위      타입
────────────────────────────────────────────────────────────────────────────────
추세 확정 연속 횟수      trend_confirm_count     3       2 ~ 6        int
  confirmed 상태가 동일 방향으로 이 값 이상 연속 → trend_confirmed = True
  반대 방향으로 이 값 이상 연속 → 추세 전환

[신뢰도 임계값]
────────────────────────────────────────────────────────────────────────────────
옵션명                   변수명                  기본값   탐색범위      타입
────────────────────────────────────────────────────────────────────────────────
confirmed 최소 신뢰도    confidence_min_confirm  0.5     0.2 ~ 0.8   float
  confidence < 이 값 → confirmed 불가, weak 강등
  핵심 지표 누락 시 -0.3/개, 보조 지표 누락 시 -0.1/개 패널티 적용

진입 허용 최소 신뢰도    confidence_min_entry    0.3     0.1 ~ 0.6   float
  confidence < 이 값 → entry_allowed = False (진입 전면 금지)
  ※ 제약: confidence_min_entry < confidence_min_confirm

▶ 스코어 구조 (고정, 최적화 대상 아님)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A-group (방향 지표, 합계 최대 ±9):
  A1: 외국인 선물 delta           가중치 ×2,  최대 ±4점
  A2: 외국인 절대값 + delta 조합              최대 ±2점
  A3: flow_score                              최대 ±2점
  A4: long_score - short_score 차이           최대 ±1점

B-group (신뢰 보정, 합계 최대 ±4, candidate 방향 기준 정렬):
  B1: OI delta × 가격 방향 조합              최대 ±2점
  B2: EMA 기울기 방향 일치                   최대 ±1점
  B3: 베이시스 방향 일치                     최대 ±1점

판정 흐름:
  A-total ≥ a_bullish_thresh → BULLISH 후보
  A-total ≤ -a_bullish_thresh → BEARISH 후보
  그 외 → NEUTRAL 후보
  ↓
  aligned_B ≥ b_confirm_min → confirmed
  aligned_B = 0 → weak
  aligned_B < 0 → transition (NEUTRAL 격하)
  ↓
  confidence ≥ confidence_min_confirm AND status=confirmed AND 동일방향 trend_confirm_count회 연속
  → entry_allowed = True

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
▶ 목적함수 (신호 품질 기반, PnL 기반 아님)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

objective = direction_acc × 100
          + confirmed_ratio × 20
          - neutral_penalty × 30
          + entry_count 보정 (entry=0 → -50, entry<3 → -10×부족수)
          + entry_rate 보정 (3~15% 범위 → +10, 25% 초과 → -10)

항목                     설명
────────────────────────────────────────────────────────────────────────────────
direction_acc           entry_allowed 신호의 5분 후 가격 방향 적중률 (0~1)
confirmed_ratio         전체 5분 틱 중 confirmed 상태 비율 (0~1)
entry_rate              전체 5분 틱 중 entry_allowed 비율 (0~1, 3~15% 선호)
neutral_penalty         A-score가 강한데(≥ a_bullish_thresh×0.7) NEUTRAL 판정한 비율

옵션                     기본값   설명
────────────────────────────────────────────────────────────────────────────────
--dates YYYY-MM-DD       없음    쉼표 구분 날짜 직접 지정 (--auto와 중복 불가)
--auto                   False   자동 루프: 새 날짜 탐지 시 자동 실행 (무한 반복)
--random N               300     Monte Carlo 랜덤 탐색 trial 수
--bayes N                150     Bayesian(Optuna TPE) 최적화 trial 수
--n-days N               10      자동 모드에서 탐지할 최근 정규장 날짜 수
--sleep N                300     자동 모드에서 새 날짜 없을 때 대기 초
--loops N                0       자동 루프 반복 횟수 (0=무한)
--top N                  0       결과 상위 N건 조회 (0=조회 안 함)
--seed N                 없음    랜덤 시드 (재현성)
--source-db PATH         mmean.db   입력 DB (읽기 전용)
--sim-db PATH            pulse_sim.db  결과 저장 DB

             ema_fast_slope, oi_value, oi_delta, basis, vwap, foreign_buy

  neutral_penalty REAL    NEUTRAL 오판 비율
  signal_count    INTEGER 전체 5분 신호 수
  entry_count     INTEGER entry_allowed 신호 수
