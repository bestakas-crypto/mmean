1부. 전략 (STRATEGY)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1-1. 왜 이 체계를 만드는가
────────────────────────────────────────────────────────────────────────────────
기존 시스템은 3분 단위 MarketAnalyst LLM이 단독으로 시장을 판단했다.
이 구조는 단기 유연성은 있으나 오늘의 방향성을 유지하는 안정성이 부족했다.
서버 재시작 시 분석이 초기화되고, 단기 노이즈에 반응하는 문제가 반복되었다.

2026-03-23 실전 관찰에서 확인된 사실:
  - 외국인은 선물 -8,944계약을 하루 종일 순매도
  - 기관은 현물 팔고 선물 매수 (역차익거래)
  - 개인은 현물 저가매수 후 익절
  - 이 구조를 조기에 파악했다면 하루 종일 숏 방향만 유지하면 됐다

결론: 하루의 힘(전략)을 먼저 잡고, 그 안에서 단기 타이밍(전술)을 운용해야 한다.


1-2. 2계층 신호 체계
────────────────────────────────────────────────────────────────────────────────
[1계층] 5분 전략 신호 — PulseEngine (규칙 기반)
  역할  : 오늘 장의 전반적인 방향과 힘을 판단
  출력  : BULLISH / NEUTRAL / BEARISH + 신뢰도 + 스코어 상세
  주체  : 규칙 기반 스코어링 엔진 (LLM 아님)
  이유  : 반응속도, 일관성, 비용, 장애 위험 모두 규칙 기반이 유리
          5분 전략 방향은 BULLISH/NEUTRAL/BEARISH 3가지이며
          핵심 지표(외국인, OI, flow_score, 베이시스)의 조합으로 충분히 커버 가능

[2계층] 3분 전술 신호 — MarketAnalyst (LLM 유지)
  역할  : 단기 시장 상태와 진입 타이밍 판단
  출력  : TREND_UP / TREND_DOWN / VOLATILE / CHOPPY /
          SPIKE_REVERSAL / REVERSAL_UP / REVERSAL_DOWN
  주체  : LLM (기존 유지)
  이유  : 복잡한 단기 패턴 인식, 설명 생성에 LLM이 유리

[검증] 30분 LLM 검증 — PulseValidator
  역할  : PulseEngine 판단이 LLM과 일치하는지 30분마다 확인
  불일치시: 경고 / 진입 금지 / 포지션 검토


1-3. 선물과 현물의 관계
────────────────────────────────────────────────────────────────────────────────
선물이 현물을 선도(lead)한다.
  - 레버리지가 크고 거래비용이 낮아 정보가 먼저 반영됨
  - 기관/외국인 같은 정보 우위 세력이 선물을 먼저 움직임
  - 차익거래자들이 선물-현물 가격 차이를 메우면서 현물이 따라옴

기관의 현물 매도 + 선물 매수 패턴 = 역차익거래
  - 선물이 현물 대비 저평가일 때 발생
  - 돈을 이동시키는 것이 아니라 가격 왜곡을 이용한 차익 포지션
  - 이 패턴이 나타나면 기관의 선물 매수를 단순 매수세로 오해하면 안 됨


1-4. 추세 방향 결정 규칙
────────────────────────────────────────────────────────────────────────────────
추세 확정   : PulseEngine 동일 방향 3회 연속 (15분)
추세 전환   : 반대 방향 3회 연속 (15분)
추세 미확정 : 3회 미충족 구간 → 진입 금지

예시:
  10:10 BEARISH (1회)
  10:15 BEARISH (2회)
  10:20 BEARISH (3회) → BEARISH 추세 확정

  이후:
  10:25 BULLISH (역방향 1회)
  10:30 BULLISH (역방향 2회)
  10:35 BULLISH (역방향 3회) → 추세 전환, BULLISH 확정


1-5. 횡보(Sideways) 규칙
────────────────────────────────────────────────────────────────────────────────
[횡보 진입]
  가격이 VWAP ± (ATR × 0.5) 이내에서 5분 이상 지속

  설계 근거:
    중심선 VWAP = 시장 공정가치 (자연스러운 기준)
    범위 ATR×0.5 = 시장 변동성에 자동 비례
    예) ATR=5pt → VWAP ± 2.5pt 이내 5분 유지 시 횡보 선언

[횡보 해제] — 아래 3가지 모두 충족
  ① 가격이 VWAP ± ATR×0.5 레인지 밖으로 이탈
  ② 이탈 방향으로 2분(2틱, 1분 단위 기준) 연속 유지
  ③ 아래 중 1개 이상 충족
     · 해당 방향 점수 우위 (long_score vs short_score)
     · EMA 기울기 해당 방향 (ema_fast_slope 부호)
     · 외국인 delta 해당 방향

  설계 근거:
    ①②: 이탈 신뢰성 확보 (노이즈 필터)
    ③  : 세 카테고리(기술/점수/수급) 분산 → 단일 지표 오신호 방지


1-6. 진입 금지 조건
────────────────────────────────────────────────────────────────────────────────
아래 중 하나라도 해당하면 신규 진입 금지:
  □ 횡보 상태 (SidewaysDetector 활성)
  □ 추세 미확정 (3회 연속 미충족)
  □ MarketAnalyst = CHOPPY 또는 VOLATILE
  □ 진입 방향이 PulseEngine 방향과 역방향
  □ PulseValidator 강한 불일치 경보 발생

2부. 설계 (DESIGN)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2-1. 입력 데이터 정의
────────────────────────────────────────────────────────────────────────────────
[수급 데이터] — 가장 중요
  외국인 선물 절대값    : 오늘 누적 순매수 계약수        investor_cache
  외국인 선물 delta     : 최근 5분간 변화량              직전값 차분
  기관 선물 절대값      : 오늘 누적 순매수 계약수        investor_cache
  기관 선물 delta       : 최근 5분간 변화량              직전값 차분
  외국인 현물 delta     : 현물 순매수 방향               KIS TR
  기관 현물 delta       : 현물 순매수 방향               KIS TR

[시장 구조 데이터]
  OI (oi_value)         : 미결제약정 절대값              regime_ticks
  OI delta (oi_delta)   : 5분간 변화량                   regime_ticks
  베이시스              : 선물 - 현물 가격차             regime_ticks
  베이시스 방향         : 5분간 확대/축소                계산

[기술적 지표]
  flow_score            : 외국인/거래량/베이시스 종합    regime_ticks
  ema_fast_slope        : 단기 EMA 기울기                regime_ticks
  long_score/short_score: 방향성 점수                    regime_ticks
  price_vs_vwap         : 현재가 vs VWAP 괴리            regime_ticks
  volume_burst          : 거래량 상대적 크기             regime_ticks


2-2. 지표 역할 분리 (핵심 설계 원칙)
────────────────────────────────────────────────────────────────────────────────
모든 지표를 동일 비중으로 합산하지 않는다.
지표를 역할별로 레이어로 분리한다.

[A] 방향 지표 — 시장 방향에 직접 관련
  · 외국인 선물 delta       ← 방향성 자금의 핵심
  · 외국인 현물 delta       ← 선물과 동조 여부 확인
  · flow_score              ← 외국인/거래량/베이시스 종합
  · long_score - short_score ← 시스템 내부 방향 판단

[B] 추세 강화 지표 — 방향의 지속성 확인
  · OI delta                ← 신규 진입인지 청산인지 구분
  · EMA 기울기 (ema_fast_slope) ← 가격 구조가 따라가는지
  · 베이시스 방향           ← 선물-현물 압력 확인

[C] 실행 제한 지표 — 방향 신뢰를 깎는 것
  · 횡보 상태 (RANGE)       ← 방향성 없음
  · MarketAnalyst CHOPPY    ← 단기 노이즈
  · OI 감소 동반            ← 추세 소멸 가능성
  · 외국인 delta 둔화       ← 매수세 약화 신호

★ 확정 — SidewaysDetector ↔ MarketAnalyst CHOPPY 계층 정의
  (외부 검토 반영, 2026-03-23 확정)

  RANGE  (SidewaysDetector 활성) = 하드 블록 (Hard Block)
    → 가격이 VWAP ± ATR×0.5 이내 5분 지속
    → 조건 충족 즉시 진입 전면 금지
    → 기존 포지션 청산 검토
    → 어떤 다른 신호도 override 불가

  CHOPPY (MarketAnalyst 판정)    = 소프트 블록 (Soft Block)
    → LLM이 단기 노이즈/방향 없음으로 판정
    → 신규 진입 금지, 기존 포지션 유지 가능
    → RANGE가 해제된 경우에도 CHOPPY면 진입 금지 유지

  우선순위: RANGE > CHOPPY
    RANGE 활성 중 CHOPPY 판정 → RANGE 규칙 적용 (강화만, 완화 없음)
    RANGE 해제 후 CHOPPY 잔존 → CHOPPY 규칙 적용 (소프트 블록 유지)
    둘 다 없을 때만 진입 허용

  이 계층은 코드에 고정한다. 운영 중 임의 변경 불가.

지표별 역할 근거:
  외국인 선물 delta   → 방향성 자금의 핵심이므로 가중치 최상위
  OI                  → 신규 진입 vs 청산 구분 → 강화 지표 (방향 지표 아님)
  베이시스            → 선물-현물 괴리 압력 → 보조 강화 지표
  EMA 기울기          → 가격 구조 확인 → 방향 보정용


2-3. 2단계 스코어링 구조
────────────────────────────────────────────────────────────────────────────────
[1단계] 방향 점수 계산
  A그룹 지표만 사용
  결과: BULLISH 후보 / NEUTRAL 후보 / BEARISH 후보

[2단계] 신뢰 보정 점수
  B그룹으로 후보 방향의 신뢰도를 보정
  C그룹으로 방향 신뢰를 깎음
  결과: 확정(confirmed) / 약함(weak) / 전환중(transition)

예시:
  방향 점수 = -4 → BEARISH 후보
  신뢰 보정 = +2 → BEARISH 확정 (신뢰 높음)

  방향 점수 = -4 → BEARISH 후보
  신뢰 보정 = -2 → BEARISH 약함 (방향은 있으나 신뢰 낮음)
             → 사이즈 축소 또는 진입 보류

  방향 점수 = -4 → BEARISH 후보
  신뢰 보정 = -4 → NEUTRAL 처리 (불확실성 과다)


2-4. 지표별 등급화 스코어 (v1 초기값)
────────────────────────────────────────────────────────────────────────────────
처음부터 정밀 수치(0.37, 0.22...)를 쓰지 않는다.
3~5단계 구간화로 시작한다.

[A1] 외국인 선물 delta (가중치 ×2, 범위 ±4)
  delta > +1,000 계약   : +2
  delta > 0             : +1
  delta 0 근방          :  0
  delta < 0             : -1
  delta < -1,000 계약   : -2

[A2] 외국인 선물 절대값 + delta 방향 조합 (±2)
  누적 매수 + delta 증가 : +2  (매수세 강화)
  누적 매수 + delta 감소 : +1  (매수세 약화)
  누적 매도 + delta 감소 : -1  (매도세 약화)
  누적 매도 + delta 증가 : -2  (매도세 강화)

[A3] flow_score (±2)
  > +0.5   : +2
  +0.1~+0.5: +1
  -0.1~+0.1:  0
  -0.5~-0.1: -1
  < -0.5   : -2

[A4] long_score - short_score (±1)
  차이 > +0.2  : +1
  차이 < -0.2  : -1
  그 외         :  0

[B1] OI delta × 가격 방향 조합 (±2)
  OI 증가 + 가격 상승 : +2  (신규 롱 진입)
  OI 증가 + 가격 하락 : -2  (신규 숏 진입)
  OI 감소 + 가격 상승 : +1  (숏 청산)
  OI 감소 + 가격 하락 : -1  (롱 청산, 추가 하락 가능)

[B2] EMA 기울기 (±1)
  분명한 상승 (slope > +0.05) : +1
  약한 상승                   : +0.5
  중립                        :  0
  약한 하락                   : -0.5
  분명한 하락 (slope < -0.05) : -1

[B3] 베이시스 상태 (±1)
  고평가(>+0.3) + 확대 중 : -1  (선물 매도 압력)
  저평가(<-0.3) + 확대 중 : +1  (선물 매수 압력)
  중립 또는 수렴 중        :  0

[C1] 실행 제한 — 횡보/잡음 (방향과 무관하게 적용)
  횡보 상태 활성 (RANGE)            : 하드 블록 — 진입 전면 금지
  MarketAnalyst = CHOPPY/VOLATILE   : 소프트 블록 — 신규 진입 금지
  OI 감소 + flow_score 중립 동시    : 신뢰 -1
  외국인 delta 3틱 연속 둔화        : 신뢰 -1

★ 확정 — 데이터 부재 시 Fallback 정책
  (외부 검토 반영, 2026-03-23 확정)

  기본 규칙:
    데이터 없음(None/NaN/미수신) → 해당 지표 점수 0점 처리 (중립)
    단, 해당 지표 누락 플래그를 confidence 계산에 반영

  지표 중요도별 confidence 감점:
    핵심 지표 누락 (외국인 선물 delta, flow_score)
      → confidence -0.3 per item
      → 2개 모두 누락 시 방향 확정 금지, 진입 제한

    보조 지표 누락 (OI, EMA, 베이시스)
      → confidence -0.1 per item
      → 단독 누락은 허용, 점수만 감산

    참고 지표 누락 (volume_burst, long/short 비율 등)
      → confidence 영향 없음, 0점 처리

  데이터 지연 처리:
    마지막 유효값 최대 2분 유지 후 부재로 처리

  진입 제한 임계:
    confidence < 0.5 → 확정(confirmed) 상태 불가
    confidence < 0.3 → 진입 전면 금지

  핵심 지표 누락 시 강제 규칙:
    외국인 선물 delta 누락 → 방향 확정 금지
    flow_score 누락        → 방향 확정 금지
    둘 다 누락             → NEUTRAL 강제, 진입 금지

  이 정책은 코드에 상수로 고정한다.
    CONFIDENCE_PENALTY_CORE  = 0.3   # 핵심 지표 누락당 감점
    CONFIDENCE_PENALTY_SUB   = 0.1   # 보조 지표 누락당 감점
    CONFIDENCE_MIN_CONFIRM   = 0.5   # confirmed 상태 최소 신뢰도
    CONFIDENCE_MIN_ENTRY     = 0.3   # 진입 허용 최소 신뢰도
    DATA_STALE_SEC           = 120   # 데이터 유효 유지 시간 (초)


2-5. 최종 판단 기준 (v1 초기값)
────────────────────────────────────────────────────────────────────────────────
방향 점수 합산 (A그룹, 최대 ±9):
  ≥ +4  : BULLISH 후보
  ≤ -4  : BEARISH 후보
  그 외  : NEUTRAL 후보

신뢰 보정 합산 (B그룹, 최대 ±4):
  후보 + 신뢰보정 ≥ +1 : 확정(confirmed)
  후보 + 신뢰보정 = 0  : 약함(weak)
  후보 + 신뢰보정 ≤ -1 : NEUTRAL로 격하

추세 확정:
  동일 방향 confirmed 3회 연속 → 추세 확정
  또는 방향 confirmed + 신뢰보정 ≥ +2 + 외국인/EMA/OI 동시 일치 → 즉시 확정


2-6. 30분 LLM 검증 (PulseValidator)
────────────────────────────────────────────────────────────────────────────────
[일치]          엔진 = LLM 방향      → 정상, 로그 기록
[약한 불일치]   엔진 BULLISH ↔ LLM NEUTRAL (또는 반대)
                → 경고 로그, 신규 사이즈 50% 축소
[강한 불일치]   엔진 BULLISH ↔ LLM BEARISH (또는 반대)
                → 신규 진입 전면 금지, 기존 포지션 손절선 타이트

연속 불일치 처리:
  1회 강한 불일치 → 진입 금지, 대기
  2회 연속 강한 불일치 → 기존 포지션 전량 청산, 엔진 강제 NEUTRAL
  불일치 해소 → 2회 연속 일치 후 정상 복귀 (1회만으로 즉시 복귀 금지)

활용:
  불일치 로그를 누적해서 주기적 캘리브레이션 자료로 활용한다.
  자주 불일치가 발생하면 스코어 임계값 또는 가중치 조정 신호로 본다.

★ 확정 — PulseValidator LLM 호출 실패 시 Fallback 정책
  (외부 검토 반영, 2026-03-23 확정)

  1회 실패 (timeout / 오류):
    → 직전 검증 결과 그대로 유지
    → 경고 로그 기록

  2회 연속 실패:
    → validator 비활성 상태로 전환
    → 신규 진입 사이즈 50% 제한 (half 모드)
    → 대시보드에 "LLM 검증 비활성" 표시

  비활성 후 복귀 조건:
    → LLM 호출 2회 연속 성공 시 정상 복귀
    → 1회 성공만으로 즉시 복귀 금지

  이 정책은 코드에 상수로 고정한다. 운영 중 임의 변경 불가.
    VALIDATOR_FAIL_FALLBACK  = 1   # 1회 실패 → 직전 결과 유지
    VALIDATOR_FAIL_HALF      = 2   # 2회 실패 → half 모드
    VALIDATOR_RECOVER_COUNT  = 2   # 정상 복귀 필요 연속 성공 횟수

────────────────────────────────────────────────────────────────────────────────

[PulseScorer] — 사후 자동 채점

  성공/실패 기록
  실패 유형 분류:
    · 과민반응: 너무 자주 방향 전환

[PulseCalibrator] — 자동 보정

  가장 문제가 큰 항목 1개만 소폭 수정 후 재검증

★ 최종 목표:
  누적 데이터 기반으로 자동 산출된 가중치/임계값으로
  5분 전략 신호를 판별하는 자기보정 엔진 구현

3-4. 기존 LLMPulse 전환 전략
────────────────────────────────────────────────────────────────────────────────
즉시 전환하지 않는다. 병행 운영 후 비교 검증한다.

1~2주: PulseEngine + LLMPulse 동시 실행
  → 두 신호 일치율 측정
  → 불일치 케이스 원인 분석
  → 스코어 임계값 캘리브레이션

검증 완료 후:
  → LLMPulse 비활성화
  → PulseEngine 단독 운영
  → LLM은 PulseValidator(30분)로만 사용

3-6. 주의사항 및 리스크
────────────────────────────────────────────────────────────────────────────────
① 현물 수급 데이터 수집
  - 기관/외국인 현물 delta를 실시간으로 받는 KIS TR 확인 필요
  - 수집 불가능하면 해당 지표 제외하고 나머지로 운영

② 외국인 delta 계산
  - 현재 investor_cache에 절대값만 저장
  - 직전 절대값을 별도 보관하여 delta 계산하는 로직 추가 필요

③ 임계값 초기값은 가설
  - v1의 ±4, ±3 등 임계값은 모두 초기 가설
  - 실전 로그 없이 "정답"이 없음
  - 너무 자주 바꾸지 말고 최소 3거래일 데이터 후 1개씩 조정

④ PulseEngine 단독 운영 전 충분한 검증
  - LLMPulse와 병행 없이 바로 전환하면 안 됨
  - 일치율 80% 이상 확인 후 전환 권장

⑤ 규칙 복잡도
  - 지표를 계속 추가하면 규칙이 꼬임
  - 초기 v1은 핵심 4~6개 지표 중심으로 시작
  - 지표 추가는 분석 근거가 생긴 후 신중하게

4부. 핵심 원칙 요약
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"5분 전략 방향 엔진은 지표를 동일 비중으로 합산하지 않고,
 방향 지표·추세 강화 지표·실행 제한 지표로 역할을 분리하여 설계한다.
 방향 판단은 외국인 선물 수급과 flow_score를 중심으로 하되,
 OI·EMA 기울기·베이시스는 신뢰 보정에 사용하고,
 횡보/잡음 상태는 별도 제한 규칙으로 처리한다."

"가중치와 임계값은 처음부터 최적화하려 하지 말고,
 지표를 역할별로 분리한 뒤 등급화된 규칙 엔진으로 시작하고,
 로그를 쌓아 점진적으로 보정하는 방식으로 접근한다."

"반드시 이겨야 하는 지표(외국인 선물 delta, flow_score)와
 있으면 좋은 보강 지표(OI, EMA, 베이시스)와
 행동 제한 지표(횡보, CHOPPY)를 명확히 구분한다."
