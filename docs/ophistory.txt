  확정 원칙:
    진입 결정      → 엔진 전담 (속도 우선)
    손절 실행      → 엔진 전담 (속도 우선)
    익절 실행      → 엔진 전담
    청산 판단 지원 → 엔진 + LLM ("나와라" 신호만, "버텨라" 신호 없음)
    파라미터 폭    → LLM (sl_ticks, trailing_ticks, enter_score 범위 제안)
    큰 흐름 판단   → LLM 10분 (LLMPulse)
  비대칭 권한 원칙:
    LLM은 포지션을 늘리는 방향보다 줄이고 나오는 방향에 더 큰 권한
    WA_MAX_UP   = +0.10  (진입 확대 제한)
    WA_MAX_DOWN = -0.20  (청산 방향 확대 허용)
    → 이 비대칭은 향후 청산 트리거 확장 시에도 동일하게 적용
  현재 구현 한계: LLM이 직접 청산 명령 불가, weight_adjust(size 조정)만 가능
  개선 로드맵:
    A-011: MarketAnalyst view → 청산 플래그 배선 (데이터 검증 후)
    A-012: LLM exit 권한 구현 — FORCE_EXIT_LLM 트리거 추가 (2026-04월 이후)
