analyzer_app.py
  메인 진입점. Flask 서버 + 엔진 시작.
  시작 게이트: build_runtime() → 비밀번호 검증 → fill_ws 시작 → 대시보드

sim.py
  파라미터 최적화 시뮬레이션 통합 CLI.
  day/night 시뮬레이션, validation, adopt, stress 테스트를 메뉴로 실행.
  내부적으로 sim_opt/day_sim.py, sim_opt/night_sim.py 를 subprocess로 호출.

day_pattern.py
  regime_ticks 데이터를 분석해 일별 장세 패턴 자동 분류.
  패턴: TREND_UP / TREND_DOWN / REVERSAL_UP / REVERSAL_DOWN /
        V_SHAPE / MORNING_SPIKE / SIDEWAYS 등
  결과를 mmean.db의 session_patterns 테이블에 저장.

path_setup.py
  서브디렉토리(core, config, db 등)를 sys.path에 등록하는 부트스트랩.
  analyzer_app.py, sim.py 등 진입점 최상단에서 import.

실행 모드 4단계
================================================================================

  OFF     데이터 수집만. 주문 없음. (기본값 — 재기동 시 항상 이 모드로 시작)
  VIRTUAL 내부 시뮬레이션만. KIS API 호출 없음.
  PAPER   KIS 모의계좌 실제 주문. (ORDER_ENV=virtual, 비밀번호 불필요)
  LIVE    KIS 실계좌 실제 주문. (EXECUTION_ENABLED=true + 비밀번호 필요)

================================================================================
파라미터 최적화 파이프라인
================================================================================

  [0] day_pattern.bat  장세 패턴 분류 → session_patterns 저장 (시뮬레이션 전 실행 권장)
  [1] sim.bat          random/bayes_opt 탐색 → sim_runs/sim_observations 저장
  [2] sim.bat          validation → 과적합 검증 (다른 날짜로 교차 검증)
  [3] sim.bat          adopt_best → 통과 config를 sim_adoptions(candidate)에 등록
  [4] sim.bat          stress 테스트 → 슬리피지 내성 확인 → stress_passed=1
  [5] rag_build.bat    sim_adoptions → RAG 문서 생성 → LLM 장중 참조
  [6] 대시보드         A/B 성과 비교 후 approve_promotion → active 파라미터 승격
